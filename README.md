## 📊 What's Inside?

| Category            | Files Included                                  | Description                                                                 |
|---------------------|--------------------------------------------------|-----------------------------------------------------------------------------|
| Basic Charts        | Pie, Donut, Column, Ribbon, Funnel, Stack        | Learn to create intuitive visualizations with ready-made PBIX files.        |
| Advanced Charts     | Advance Charts 1 & 2, Include/Exclude Charts     | Take your skills up a notch with dynamic and interactive charts.            |
| Table & Matrix      | Creating a Table, Creating a Matrix              | Represent structured data using clean, tabular formats.                     |
| Maps & Geography    | MAP CHART                                        | Visualize data across countries, cities, or regions using geo charts.       |
| Slicers & Filters   | Slicer.pbix                                      | Explore interactivity with slicers and dynamic filters.                     |
| Dataset             | global_superstore.xlsx                           | Cleaned and curated dataset to practice and build real-world dashboards.    |
